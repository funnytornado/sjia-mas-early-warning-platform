# 发布提审清单（个人主体）

上传状态：开发版本已更新到 1.0.4。评估功能加入后，个人主体无法开通医疗健康类目，**不可提交审核**，当前只能走体验版内测。

下面 1–4 步只能在 mp.weixin.qq.com 后台操作，代码侧已全部就绪。

## 1. 基本设置（首次必做）

- 名称：家庭记录助手
- 简介：记录化验、症状与用药，导出就诊摘要；数据只存本机，不做医学判断
- 头像：准备一张 144×144 以上的图片
- 服务类目：在个人主体可选范围内选「工具」这类，不能选医疗健康
- 注意：名称与简介里不要出现诊断、治疗、用药建议等表述

## 2. 小程序备案（不备案不能发布）

- 位置：设置 → 基本设置 → 小程序备案
- 个人主体材料：身份证、手机号、邮箱
- 备案要经平台与通信管理局，通常需要数个工作日，建议今天就提交

## 3. 用户隐私保护指引

- 位置：设置 → 服务内容声明 → 用户隐私保护指引
- 必须声明：相册（仅写入）、摄像头 —— 因为用到 wx.chooseMedia 拍照/选图
- 其余接口（本地存储、文件写入、打开文档、转发文件）按后台实际勾选项如实填写
- 不声明的话，相关功能会在审核与真机上被拦截

## 4. 提交审核

- 位置：管理 → 版本管理 → 开发版本 1.0.0 → 提交审核
- 测试提示建议写：纯本地记录工具，无需登录，打开即可录入；建议手填一份化验与一条用药走完流程；Word 导出请在真机上测试
- 功能页面：pages/home/home、pages/discover/discover
- 服务类目要与实际功能一致（工具类，非医疗健康）

## 5. 审核通过后发布

- 管理 → 版本管理 → 审核版本 → 发布
- 发布后任何微信用户可搜索、扫码、分享进入

## 6. 想先小范围试用（不用等审核）

- 版本管理 → 开发版本 → 设为体验版
- 成员管理 → 添加体验成员（上限以后台显示为准）
- 这样几十人可以先用起来

## 已知风险（提审前想清楚）

- 「发现」页的就医资源仍属「医院信息」形态，政策资讯需要权威来源；审核可能就这两栏提问。要彻底规避，可把「发现」换成「关于」页（同样满足 tabBar 两项要求）。
- 工程是纯本地存储：无账号、无云端，换设备数据不跟随；审核若问「用户数据如何保存」，按实说明。
- wx.openDocument 与 wx.shareFileMessage 在开发者工具里可能受限，务必在真机上验证 Word 导出与转发。

## 代码侧已完成的事

- 无后端、无网络请求、无 OCR；不采集任何用户信息
- 评估页按已发表标准（2016 PRINTO、2004 HLH、MS 评分表）给出静态提示，非医疗器械、不构成诊断，须由医生判断
- 无 UGC 社区（病友交流已删除）
- 已补 sitemap.json；工程名与描述已去掉病名
- 自检覆盖：WXML 编译陷阱、导航结构、涉医与社区字样残留、input 高度、Word 生成与转义、本地存储读写
